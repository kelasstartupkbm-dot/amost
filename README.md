# AMOST

Amikom Mobile Outdoor Sport Tracking

## Overview

AMOST adalah platform tracking olahraga outdoor berbasis GPS yang mendukung:

- Sepeda
- Lari
- Jalan Sehat
- Trail Run
- Event Outdoor

## Features

- Live GPS Tracking
- Event Management
- Ticketing System
- Participant Monitoring
- Activity Statistics

## Technology

### Frontend
- Next.js
- Tailwind CSS

### Backend
- NestJS

### Database
- PostgreSQL

### Hosting
- Railway
